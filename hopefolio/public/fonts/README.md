# Self-hosted type

These unmodified Latin variable WOFF2 files come from the official Fontsource
packages, downloaded from the npm registry on September 6, 2026. They are served
through `next/font/local` so production builds and previews do not depend on a
connection to Google Fonts.

- `@fontsource-variable/recursive@5.3.0`: `recursive-latin-full-normal.woff2`
  preserves `CASL`, `CRSV`, `MONO`, `slnt`, and `wght`.
- `@fontsource-variable/newsreader@5.3.0`: the normal and italic
  `newsreader-latin-opsz-*.woff2` files preserve `opsz` and `wght`.

Both families are licensed under the SIL Open Font License 1.1. The complete
upstream license and copyright notices are retained in each family directory.
